조건부확률 · 연쇄법칙 · 자기회귀

한 조각씩 이어지는 생성을 코드 토큰의 확률로 계산합니다.
Context C = "# 0부터 9까지 숫자를 출력한다"
P(for | C) = 0.60
P(i | C, for) = 0.50
P(in | C, for, i) = 0.80
※ 설명용 가상 확률입니다. 실제 Copilot/GPT 내부 확률을 측정한 값은 아닙니다.
(1) for → i → in이 이 순서로 연속 생성될 확률을 구하세요.
(2) 조건이 C → C, for → C, for, i로 누적되는 이유를 조건부확률과 Context라는 말을 사용해 설명하세요.
