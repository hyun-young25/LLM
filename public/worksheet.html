조건부확률 · 연쇄법칙 · 자기회귀 생성

체험에서 본 ‘한 조각씩 생성’을 코드 토큰의 조건부확률로 표현합니다.
Context C = "# 0부터 9까지 숫자를 출력한다"
P(for | C) = 0.60
P(i | C, for) = 0.50
P(in | C, for, i) = 0.80
※ 위 확률은 생성 원리를 설명하기 위한 가상 값이며, 실제 Copilot/GPT 내부 확률을 측정한 값이 아닙니다.
(1) for → i → in이 이 순서로 연속 생성될 확률을 구하세요.
(2) 세 확률에서 조건이 C → C, for → C, for, i로 계속 달라지는 이유를 ‘조건부확률’과 ‘Context’라는 말을 사용해 설명하세요.
